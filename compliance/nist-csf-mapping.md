# 1. Purpose

The purpose of this document is to map BrightCare Medical Group cybersecurity controls, policies, and security initiatives to the NIST Cybersecurity Framework (CSF).

This mapping supports:

- Cybersecurity governance
- HIPAA compliance efforts
- Security maturity assessments
- Risk management activities
- Compliance documentation
- Security program development

The mapping aligns organizational safeguards and processes with the six NIST CSF core functions:

1. Govern
2. Identify
3. Protect
4. Detect
5. Respond
6. Recover

---

# 2. NIST CSF Overview

The NIST Cybersecurity Framework provides guidance for managing and reducing cybersecurity risk through a structured approach based on industry best practices.

The framework helps organizations:

- Improve cybersecurity posture
- Protect sensitive information
- Detect and respond to threats
- Improve operational resilience
- Support regulatory compliance

# 5. Protect (PR)

---

## Current Controls

| Area | Existing Controls |
|---|---|
| Access Control | Role-based access partially implemented |
| MFA | MFA enabled for selected systems |
| Endpoint Protection | Antivirus and endpoint protection deployed |
| Encryption | Partial encryption deployment |
| Security Awareness | Security awareness training conducted |
| Backup Systems | Backup solutions implemented |
| Email Security | Spam filtering and malware protection enabled |

---

## Identified Gaps

- MFA not universally enforced
- Weak password practices
- Limited endpoint encryption coverage
- Inconsistent security awareness maturity
- Limited removable media controls

---

## Recommended Improvements

- Enforce MFA organization-wide
- Implement password manager solutions
- Expand encryption deployment

- Restrict unauthorized USB usage
